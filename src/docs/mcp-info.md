### 什么是 MCP

🎉 [MCP（模型上下文协议）](https://modelcontextprotocol.io/docs/getting-started/intro)是一种用于将 AI 应用程序连接到外部系统的开源标准。

### MCP 接入数量限制

平台限制了每个用户添加 MCP 配置的最大数量为 `30` 个，过多的 MCP 会导致上下文 token 消耗大，为了节省资源做此限制。
